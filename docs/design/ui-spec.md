# lol-f 暗色 UI 设计规范

> 概念：**墨底 + 台灯**。中性墨黑是夜色，琥珀暖橙是工作台上亮着的灯。
> 受众是开发者，典型场景是夜间长时间使用工具与阅读文章——暗色不是皮肤，是这个产品的原生环境。
> 色彩哲学借自 Riot Client：**色彩分两级**——系统级琥珀管交互，内容级工具专属色管身份。

可视化预览：用浏览器打开同目录的 `preview.html`。
令牌落地：`src/static/styles/theme.less`（在 `global.less` 中 `@import` 即可）。

---

## 1. 设计原则

1. **层级靠明度，不靠阴影。** 暗色下灰色投影几乎不可见。背景分四级阶梯，越浮越亮（色值见 §2.1）。需要分隔时先用发丝边框，最后才考虑阴影（仅弹层用）。
2. **琥珀色只做一件事：指引。** 它只出现在可交互、被激活、需要用户注意的地方。页面里琥珀越少越值钱——一个屏幕上主强调元素不超过 2 处。
3. **色彩分两级，各管一件事。** 系统级：琥珀只给交互与激活。内容级：每个工具一个专属色（见 §2.4），管身份与路由级选中态。两种色不出现在同一个元素上。背景与文字保持无彩色，不做第三种大面积色相装饰。
4. **文字对比度是底线。** 正文与背景的对比度不低于 WCAG AA（4.5:1），正文级组合均已实测达标（见 §2.5）；辅助级文字仅用于非关键内容，控件边界不低于 3:1（WCAG 1.4.11）。

## 2. 色彩

### 2.1 背景层级

底色为**中性墨黑、不带色相**（借自 Riot Client：无色彩底让任何色相的内容图片放上去都和谐）。四级阶梯，越浮越亮。

| 令牌                         | 值                    | 用途                                          |
| ---------------------------- | --------------------- | --------------------------------------------- |
| `--bg-base`                  | `#131417`             | 页面底色。**不用纯黑 `#000`**（刺眼、无层次） |
| `--bg-raised`                | `#1A1C20`             | 卡片、面板、侧栏                              |
| `--bg-overlay`               | `#22252B`             | Modal、Drawer、Popover、下拉菜单              |
| `--bg-hover` / `--bg-active` | `#2A2E35` / `#32363F` | 列表项、按钮的悬浮/按下态                     |

### 2.2 文字

| 令牌               | 值        | 用途                                                  |
| ------------------ | --------- | ----------------------------------------------------- |
| `--text-primary`   | `#E8ECF1` | 主文字。微柔的白，**不用纯 `#FFF`**（长时间阅读刺眼） |
| `--text-secondary` | `#9AA7B4` | 次要说明、表单备注                                    |
| `--text-tertiary`  | `#788290` | 占位符、时间戳等辅助信息（4.5:1，勿用于正文）         |
| `--text-disabled`  | `#454F5B` | 禁用态                                                |
| `--text-on-accent` | `#1A1206` | 琥珀底上的文字（深棕黑，不是纯白）                    |

### 2.3 强调与语义色

| 令牌                                             | 值                                            | 用途                                                      |
| ------------------------------------------------ | --------------------------------------------- | --------------------------------------------------------- |
| `--accent`                                       | `#FA8C16`                                     | 主按钮填充、开关、选中态                                  |
| `--accent-hover` / `--accent-active`             | `#FBA33F` / `#E07B0A`                         | 强调色交互态                                              |
| `--accent-text`                                  | `#FFB75C`                                     | 链接、文字级强调。**暗底上的文字琥珀要比填充琥珀亮一度**  |
| `--accent-bg`                                    | `rgba(250,140,22,.12)`                        | 选中行底色、琥珀 tag 底                                   |
| `--success` / `--error` / `--info` / `--warning` | `#4CC38A` / `#F2555A` / `#5AA9FF` / `#F0C040` | 语义反馈，仅用于状态表达，不作装饰                        |
| `--success-bg` / `--error-bg`                    | 语义色 12% 透明底                             | 新增/删除行底、语义 tag 底（沿用 `--accent-bg` 12% 惯例） |

### 2.4 工具专属色（内容带色）

借自 Riot Client 的"Installed 状态条"玩法：每个工具一个专属色，管**身份与路由级选中态**，不管交互（交互永远归琥珀）。

| 令牌              | 值        | 色相 | 工具                     |
| ----------------- | --------- | ---- | ------------------------ |
| `--tool-json`     | `#3EC6E0` | 190° | JSON 格式化 · 青         |
| `--tool-color`    | `#A78BFA` | 255° | 颜色转换 · 紫            |
| `--tool-time`     | `#E879C6` | 318° | 时间戳转换 · 洋红        |
| `--tool-base64`   | `#49DF5D` | 128° | Base64/URL 编解码 · 松绿 |
| `--tool-regex`    | `#87DF49` | 95°  | 正则测试 · 草绿          |
| `--tool-easing`   | `#C5EB84` | 82°  | 缓动曲线 · 荧光绿        |
| `--tool-jwt`      | `#D384EB` | 286° | JWT 解析 · 紫罗兰        |
| `--tool-yaml`     | `#84EBAA` | 142° | YAML/JSON 转换 · 碧绿    |
| `--tool-diff`     | `#84EBD0` | 164° | Diff 对比 · 青碧         |
| `--tool-markdown` | `#D2DF49` | 65°  | Markdown 预览 · 橄榄绿   |

取色规则（新增工具时遵守）：

1. 色相取自工具自身语义，让用户凭颜色就能认出工具；
2. HSL 饱和度 55–95%；明度分两层——**暗层 L 56–62%**、**亮层 L 70–78%**（暗底适配，两层 ΔL ≥ 12% 构成色相之外的第二区分维度）；
3. 与琥珀（≈31°）的色相间距 ≥ 30°；工具色之间：同层间距 ≥ 20°，跨层间距 ≥ 12° 且 ΔL ≥ 12%；与语义色：间距 ≥ 20° 直接合法，15–20° 需明度错位 ≥ 8%，< 15° 需明度错位 ≥ 12%（避免小尺寸下图标误读为状态反馈）；
4. 容量约 13–16 个工具（暗层 4–5 槽 + 亮层 9–11 槽）；暖色区（343–61°）被琥珀与 error/warning 封锁，暖色语义工具未来需启用 L<55% 的第三暗层，届时修订本节；
5. 用法仅限：工具卡片状态条/图标、路由级选中底（专属色 12% 透明度）、工具页标题点缀。**专属色实底上的文字一律用 `--text-on-accent`**（深棕黑），不用白字；**不可**用于按钮填充、链接文字——那是琥珀的位置。

### 2.5 关键组合对比度（WCAG 实测）

| 组合                                | 实测对比度        | 结论                             |
| ----------------------------------- | ----------------- | -------------------------------- |
| `--text-primary` × `--bg-base`      | 15.5:1            | AAA                              |
| `--text-secondary` × `--bg-base`    | 7.5:1             | AAA                              |
| `--text-tertiary` × `--bg-base`     | 4.5:1             | AA（仍仅限辅助信息，勿用于正文） |
| `--accent-text` × `--bg-base`       | 10.7:1            | AAA（链接/强调文字安全）         |
| `--text-on-accent` × `--accent`     | 7.8:1             | AA（主按钮安全）                 |
| `--text-on-accent` × 三个工具色实底 | 9.1 / 6.8 / 6.9:1 | AA（状态条深字安全）             |
| `--border-control` × `--bg-base`    | 3.6:1             | 达 WCAG 1.4.11 控件边界标准      |

### 2.6 边框

- 纯装饰分隔：`--border` = `rgba(232,236,241,.09)`，1px 发丝线（非信息性元素，对比度豁免）。
- 卡片、面板边界：`--border-strong` = `rgba(232,236,241,.16)`。
- **控件边界**（输入框、下拉框等"识别控件所必需"的边框）：`--border-control` = `#5A6472` 实色，实测 3.6:1，达 WCAG 1.4.11 的 3:1 要求。
- **禁止**在暗色界面使用纯黑或纯白边框。

## 3. 字体与排版

### 3.1 字体族

| 角色          | 字体栈                                | 说明                                            |
| ------------- | ------------------------------------- | ----------------------------------------------- |
| UI / 中文正文 | `--font-sans`（PingFang SC / 系统栈） | 中英文混排统一一套，不做"标题字体"分裂          |
| 代码 / 数据   | `--font-mono`（JetBrains Mono 优先）  | JSON 工具、代码块、版本号等**等宽即功能**的场景 |

### 3.2 字号阶梯

```
12  14  16  20  24  32  44
```

- UI 正文基准 14px（与 antd 一致）；**博客文章正文用 16px + 行高 1.75**（中文长文阅读舒适度）。
- 标题行高 1.25，正文行高 1.5。
- 44px 仅用于首页级展示标题，一个页面最多一处。

### 3.3 排版规则

- 一律**左对齐**；居中文本仅限空状态与弹窗确认。
- 文章栏宽上限 720px（<80 字符/行）。
- **不做**这些处理：标题里单独给某个词变色/变斜体；全大写标签；标题上方加装饰性小标签。

## 4. 间距 · 圆角 · 动效

- **间距**：4px 基栅，`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。组件内部用 8/12/16，区块之间用 32/48。
- **圆角**：4px（按钮、输入框）/ 8px（卡片）/ 12px（弹窗）。不搞"全站一个圆角"。
- **阴影**：仅 `--shadow-overlay`（弹层）。卡片、面板一律无阴影。
- **动效**：150ms（hover）/ 250ms（展开、切换），`cubic-bezier(.2,0,0,1)`。动效只回应用户动作，不做无触发装饰动画；遵守 `prefers-reduced-motion`。

## 5. 组件要点

| 组件            | 规则                                                                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 主按钮          | `--accent` 底 + `--text-on-accent` 字；hover 亮、active 暗                                                                                  |
| 次按钮/幽灵按钮 | 透明底 + `--border-strong` 边 + `--text-primary` 字                                                                                         |
| 禁用按钮        | 透明底 + 发丝边 + `--text-disabled` 字。**禁用态只能更暗或持平，不能比所在容器更亮**（明度=层级，更亮看起来就是可点的）                     |
| 链接            | `--accent-text`，hover 加下划线；**不要**在链接后追加「→」                                                                                  |
| 焦点            | 全站统一：`outline: 2px solid var(--focus-ring); outline-offset: 2px`，作用于 `:focus-visible`。**不用外发光**，输入框也不例外              |
| 输入框          | `--bg-base` 底 + `--border-control` 边；focus 时边框变 `--accent` 并叠加统一焦点描边                                                        |
| 选中态归属      | **路由级选中**（当前工具、当前侧栏项）→ 工具专属色 12% 底；**数据级选中**（列表行、表格行）→ `--accent-bg` 琥珀浅底。同一界面两种选中不混用 |
| 导航激活项      | `--accent-text` 字 + 600 字重，可选 2px 琥珀下划线（延续现有 `.active` 用法）                                                               |
| 代码块          | `--bg-raised` 底 + `--font-mono`；语法着色用 `--code-key/--code-string/--code-number` 专用色板，**不挪用语义色**                            |
| 工具卡片        | 图标/封面区 + 底部 4px 状态条用该工具的专属色，**状态条文字一律 `--text-on-accent`**；卡片本身无阴影、发丝边框                              |
| 空状态          | 居中，一句"发生了什么 + 下一步做什么"，配主按钮                                                                                             |
| 错误提示        | 不道歉、不含糊：说明原因和修法，如"JSON 第 3 行缺少逗号"                                                                                    |

## 6. 接入方式

### 6.1 全局样式

```less
// src/static/styles/global.less
@import './theme.less';

html {
  color-scheme: dark; // 必加：否则原生滚动条、表单控件、autofill 会渲染成亮色刺穿墨底
}

html,
body {
  background-color: var(--bg-base);
  color: var(--text-primary);
  font-family: var(--font-sans);
}

::selection {
  background-color: var(--selection-bg); // 琥珀选区，不用浏览器默认蓝紫
}
```

### 6.2 antd 主题映射（antd 6 · ConfigProvider）

`darkAlgorithm` 的默认值与规范有三处冲突，必须显式覆盖：**主按钮默认白字**（×琥珀底仅 ≈2.2:1）、**输入框默认带外发光**（违反"不用外发光"）、**派生的容器/边框色与 CSS 变量阶梯不完全一致**。完整映射如下：

```tsx
import { ConfigProvider, theme } from 'antd';

<ConfigProvider
  theme={{
    algorithm: theme.darkAlgorithm,
    token: {
      borderRadius: 8,
      colorBgBase: '#131417',
      // 钉死派生色，保证 antd 组件与自定义组件共用一套灰阶
      colorBgContainer: '#1a1c20',
      colorBgElevated: '#22252b',
      colorBgLayout: '#131417',
      colorBorder: 'rgba(232, 236, 241, 0.16)',
      colorBorderSecondary: 'rgba(232, 236, 241, 0.09)',
      colorPrimary: '#fa8c16',
      colorTextBase: '#e8ecf1',
      colorTextSecondary: '#9aa7b4',
      colorTextTertiary: '#788290',
      // 关键：琥珀底上的文字必须是深棕黑，darkAlgorithm 默认白字只有 ≈2.2:1
      colorTextLightSolid: '#1a1206',
      // 关键：关掉默认 focus 外发光，焦点统一走 --focus-ring 描边
      controlOutlineWidth: 0,
      fontFamily:
        "-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif",
    },
    components: {
      Button: { borderRadius: 4 },
      Input: { borderRadius: 4 },
      Modal: { borderRadiusLG: 12 },
    },
  }}
>
```

### 6.3 组件内使用

```less
// 任意 index.module.less
.card {
  background-color: var(--bg-raised);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  color: var(--text-primary);
}
```

## 7. 迁移说明（对现有代码）

- `global.less` 现有的 `--dark-deep` / `--dark-normal` / `--white-normal` / `--page-bg-color` / `--page-font-color` 由本规范令牌替换，旧变量保留一个版本周期后删除。
- **运行时依赖注意**：`views/Test/components/TweenDemo/index.tsx` 用 `getComputedStyle` 读取 `--page-font-color`（canvas 描边色，有 `'white'` 兜底）——迁移时改为读 `--text-primary`，否则删旧变量后 canvas 描边会静默变成纯白。
- 导航激活色 `#fa8c16`（`views/Tools/index.module.less` 的 `.active`）文字场景下改为 `var(--accent-text)`，对比度更稳；导航链接字号 20px 与规范阶梯中"20=小标题"冲突，应降为 15px 导航档。
- 迁移期新旧变量并存，新组件一律使用新令牌。

## 8. 尚未覆盖（后续版本补充）

以下暗色界面议题本版未规定，遇到对应需求时先补规范再动手：

- 长文排版细节：段落间距、引用块、表格、分割线在文章页的样式
- 图表/数据可视化色板（需与琥珀、语义色、工具色全体系错位）
- 图片与文章头图处理：暗底下高亮图是否需要暗化蒙层或发丝边框
- 骨架屏 / Loading 的视觉（现有 Loading 组件待对齐）
- 移动端断点与触控目标尺寸
- 打印样式（黑底打印需反转为浅色）
