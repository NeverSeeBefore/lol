# 像素实验室实施计划

> **执行提示：**独立任务使用子 agent；计划制定时，项目指引禁止未经用户要求的提交和推送。

**目标：**构建可复用的交互式像素画布、本地图片与视频转换工作室，以及独立的元胞自动机实验。

**架构：**Canvas 2D 绘制大量可交互像素，避免创建大量 DOM 节点。带版本号和调色板索引的帧数据连接转换器、渲染器与 JSON 导出。生命沙盘管理自己的仿真状态和画布。

**技术栈：**React 19、TypeScript 5.9、Vite 8、Less CSS Modules、浏览器 Canvas 与媒体 API。

**设计稿：**`docs/superpowers/specs/2026-10-16-pixel-lab-design.md`

## 全局约束

- 保留开始时工作区已有的未提交改动。
- 未获用户明确要求前不提交或推送。
- 媒体只在本地浏览器处理；非必要不增加依赖。
- 页面在 `src/views/Lab/experiments.ts` 注册。

## 评审重点

- 导入格式错误的 JSON 不应导致渲染崩溃。
- 视频跳转和临时对象 URL 在出错或卸载时应清理。
- 调整分辨率后，每帧像素数量仍须正确。
- 长帧或隐藏标签页不应导致播放计时漂移。
- 启用“减少动态效果”时仍应展示可用的静态画面。
