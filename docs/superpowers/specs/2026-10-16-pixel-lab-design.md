# 像素实验室设计

## 意图

在现有实验室增加可复用的像素画布与本地媒体转换工具。用户能以固定网格（默认 20×20）显示静态图或逐帧动画；每个像素在指针靠近时独立缩放，示例页能调整分辨率和效果。另增加独立的「生命沙盘」，用元胞自动机展示可编辑的离散系统。

## 范围与约束

- 沿用 React、TypeScript、Less 与现有暗色主题；新页面通过实验室清单懒加载。
- 像素画布使用 Canvas 2D 绘制与数学命中测试，避免为每个像素创建 DOM 节点。网格支持 8–96 列、8–96 行；超出范围明确拒绝或限制。
- 媒体只在本地浏览器处理，不上传。图片生成一帧；视频按用户指定帧率和时长抽样，限制帧数与输出体积。失败或不支持的格式显示可操作的说明。
- 可导出与重新导入版本化 JSON：`{version:1,width,height,palette:string[],frames:{durationMs:number,cells:number[]}[]}`。`cells` 是逐行调色板索引，长度始终为 `width*height`；颜色使用 CSS 十六进制颜色。
- 输入媒体转换采用 contain 居中策略，保留透明像素；预览和下载使用同一份元数据。组件可独立导入，不依赖实验室页面。
- 生命沙盘包含暂停、单步、随机、清空、指针绘制和规则选择，仿真随时间步进；状态更新不依赖 React 每帧重渲染。
- 尊重 `prefers-reduced-motion`，可用键盘操作页面控制，屏幕阅读器能读到预览内容的说明。

## 实现分界

- `src/components/PixelCanvas/`：类型、校验、绘制与交互组件。
- `src/views/Lab/PixelStudioPage.tsx`：组件展示、参数控制、图片/视频本地转换与 JSON 导入导出。
- `src/views/Lab/CellularLabPage.tsx`：独立的元胞自动机实验。
- `src/views/Lab/experiments.ts` 与 README：统一注册和使用说明。

## 我做的默认选择

- 调色板上限 256 色，以确定性的颜色量化控制视频数据量。
- 视频首版最多 6 秒、12 帧/秒；这是浏览器内处理和 JSON 可读性的折中。
- 新实验沿用当前实验室侧栏，不新增顶层 tab。
