# 生命沙盘：规则与实现

生命沙盘把网格视为一组 `0` / `1` 细胞。每一代同时读取旧棋盘、写入新棋盘；八邻域中，棋盘边界之外一律视为空白。页面提供生命游戏、HighLife、Seeds 三个预设，也能输入自定义 `B/S` 规则。

## 规则

`B3/S23` 表示：空白格有 3 个邻居时出生；活细胞有 2 或 3 个邻居时存活。`B36/S23` 增加了 6 邻居出生；`B2/S` 表示 2 邻居出生、活细胞不会存活。数字范围是 0–8，各组内不能重复。规则在“应用”时解析成两个位掩码，演化循环只做移位与按位判断。

## 性能与时间

棋盘保存在 `Uint8Array` 和 React ref 中，逐代演化不会让几千个格子进入 React 渲染树。单个 Canvas 负责绘制网格与细胞；`ResizeObserver` 只在容器尺寸变化时更新画布像素大小。自动播放使用 `requestAnimationFrame` 和 150 毫秒累计器；标签页隐藏时暂停，回来后从原代数继续计时，不补跑看不到的演化。系统启用“减少动态效果”时，可用“单步”观察。

指针绘制使用整数网格线算法填满两次指针事件之间经过的格子，因此快速拖动也能得到连续笔画。画布可聚焦，方向键移动光标，空格或回车切换格子。

## 观察与导出

种群曲线保留最近 80 代活细胞数。稳定态和短周期判断会把当前棋盘与最近 16 代的**完整棋盘**比较，避免“细胞数恰好相同”造成误报。

最近最多 72 张完整棋盘另存为有界历史，可导出为 `PixelScene v1` JSON，每帧 150 毫秒。这个文件能在[像素工作室格式说明](./pixel-scene-format.md)对应的页面导入播放。切换规则、修改棋盘、载入图案或调整网格时，分析历史从当前状态重新开始，以免把不同实验混在同一条时间线上。
